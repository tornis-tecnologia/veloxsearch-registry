# Writing a Spec 2.0 package

Normative text: [`spec/README.md`](spec/README.md). Worked examples:
[`packages/system/1.0.0`](../packages/system/1.0.0) (seven streams: tail,
systemd, kmsg, cpu, mem, node_exporter_metrics; grok pipelines; toggles;
dashboard) and [`packages/custom-logs/1.0.0`](../packages/custom-logs/1.0.0).
Copy their shape; do not invent new keys.

## Layout

```
packages/<id>/<version>/
  manifest.yaml                 identity, compatibility, streams, dashboards, docs, files, signature
  changelog.yaml                newest first; entry for this version required
  docs/README.{en,es,pt}.md     streams table, fields, requirements, dashboard
  img/icon.svg                  32x32, currentColor strokes, no brand marks
  streams/<stream>/
    stream.yaml                 input + fields, parsers, processors, backend
    index-template.json         {"template": {"settings", "mappings"}}   (logs/traces streams)
    ingest-pipeline.json        OpenSearch processors; `tag` on anything a field toggles/tunes
    sample-event.json           one document as it lands in OpenSearch
    test/<case>.log             raw lines fed to the pipeline as {"log": line}
    test/<case>.in.json         or: already-structured input documents
    test/<case>.expected.json   generated by scripts/pipeline_test.py --update, then reviewed
  dashboards/<name>.ndjson      saved objects with LOCAL ids and `stream:<id>` index-pattern refs
```

## Rules of thumb

- **Stream ids** are what the operator reads in an index name
  (`veloxagent-<stream>.<id>-v1`): `access`, `error`, `slowlog`, `metrics`,
  not `logs1`.
- **`signal`** is what it is for the operator; **`event_type`** is what the
  plugin emits (`fluent-bit/5.2/inputs/<plugin>.yaml` → `event_types`).
  `event_type: metrics` streams have no backend (they go to the OTLP endpoint).
- **Every plugin key you bind or fix must exist in the catalogue** with a
  compatible type; `operator_settable: false` keys go in `fixed`; `db`/state
  paths use `{state_dir}` and `{stream_tag}`.
- **Parsing happens in the ingest pipeline** (grok/dissect/json/kv), so the
  pipeline tests are meaningful and the host does less work. Fluent Bit
  parsers are offered only when the operator benefits (json/logfmt lines,
  multiline).
- **Field names** follow ECS where one exists: `@timestamp`, `message`,
  `host.name`, `process.name`, `process.pid`, `log.level`, `event.outcome`,
  `source.ip`, `url.path`, `http.request.method`, `http.response.status_code`,
  `user_agent.original`, `client.ip`, `event.duration` (ns). Keep the
  product's own names under a namespace (`nginx.*`, `postgres.*`). Always map
  `velox.integration`, `velox.stream`, `velox.package_version` as keyword.
- **Unparsed lines never get dropped**: `on_failure` keeps the line in
  `message` and sets `event.outcome: unparsed`.
- **Timestamps**: parse the log's own time into `@timestamp` with a `date`
  processor; keep the original string out of the document.
- **Pipelines**: `set` takes `value: "{{field}}"` (OpenSearch has no
  `copy_from`); never `rename` a field onto itself; `remove` temporaries at
  the end under `tag: cleanup`.
- **Lifecycle** defaults by volume: access logs 20gb/1d/30d, error logs
  10gb/7d/30d, security 90d. Expose `delete_after` as a field.
- **Dashboards**: 4–7 visualizations, one dashboard `overview`. Local ids,
  `references[].id = "stream:<id>"` for index patterns. No index-pattern
  objects in the file. Migrating a 1.x package: copy the visualization and
  dashboard lines of `integrations/<id>/saved-objects.ndjson`, drop the
  index-pattern line, rename ids to local slugs, point every
  `kibanaSavedObjectMeta.searchSourceJSON.index` reference at `stream:<id>`,
  and update field names to the new mapping.
- **i18n**: en, es, pt on every title/description, one sentence.
- **Secrets** (`type: password`) for any credential a plugin takes; never a default.
- **Allowed processors** (`processors.allow`): logs streams
  `[grep, modify, record_modifier, nest, parser, content_modifier, sql, throttle]`;
  metrics streams `[metrics_selector, labels]`; add `multiline` for stack traces.

## Checklist before you stop

```sh
python3 -I scripts/inventory.py packages/<id>/<version>          # files: + sha256
python3 -I scripts/validate_v2.py packages/<id>/<version>        # schemas + R1..R23
OPENSEARCH_URL=http://localhost:19200 python3 -I scripts/pipeline_test.py --update packages/<id>/<version>
#   → read every test/*.expected.json; fix the pipeline until the fields are right; re-run without --update
FB_VERSIONS="3.2 latest" scripts/dryrun.sh packages/<id>/<version>   # fluent-bit --dry-run (Docker)
```

A `tests/activations/<id>/<name>.json` fixture that turns on every stream
with non-default values is strongly recommended: CI dry-runs it too.
`packages/index.json` is regenerated by the maintainer (`scripts/build_index.py`); do not edit it.
